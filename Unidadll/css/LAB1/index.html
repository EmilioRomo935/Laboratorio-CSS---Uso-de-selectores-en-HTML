Unidad 2 - CSS - Laboratorio No. 1

Las reglas CSS definen cómo se debe mostrar un elemento en la página.

Reglas CSS internas, en líena y externas

Las reglas CSS se pueden aplicar de tres maneras diferentes: según la ubicación de las reglas CSS en el documento HTML. Las reglas CSS internas se definen dentro de la etiqueta head.

Reglas CSS internas

Las reglas CSS internas se definen dentro de la etiqueta head. Se utilizan para aplicar estilos a un solo documento HTML. Se colocan dentro de una etiqueta style en la sección head del documento HTML.
